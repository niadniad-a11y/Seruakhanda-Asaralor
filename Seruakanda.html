অ্যাপ হিসেবে ইন্সটল করুন

আপনার মোবাইলের হোম স্ক্রিনে যুক্ত করে সহজে ব্যবহার করুন

সহজ ডিপ্লয়মেন্ট ও সেটআপ নির্দেশিকা

⚠️ বর্তমান সংস্করণ Browser Storage Mode-এ চলছে।

User account, content এবং admin changes এই browser-এর local storage-এ সংরক্ষিত হবে। সত্যিকারের multi-user production system-এর জন্য Firebase/Supabase backend প্রয়োজন।

User Registration

User registration করলে কোনো admin approval ছাড়াই account তৈরি হবে এবং user automatically login হবে।

Admin Login

Login page থেকে Admin Login নির্বাচন করে admin password ব্যবহার করুন।

Production Setup

Commercial multi-user deployment-এর সময় Firebase Authentication + Firestore অথবা Supabase Auth + Database ব্যবহার করা উচিত।

সিস্টেম সেটআপ

এই version-এ Firebase config প্রয়োজন নেই। নিচের button শুধু local data reset করার জন্য।

সতর্কতা: এই button ব্যবহার করলে এই browser-এর সব user, settings, notice, project এবং contribution data মুছে যাবে।
